# Последний рубеж — Протокол заражения

Оригинальный изометрический шутер с зачисткой заражённого промышленного комплекса, вдохновлённый форматом Alien Shooter. Три связанных уровня: грузовой терминал, лаборатория и реактор с маткой. Стены блокируют движение, пули и видимость; мутанты обходят препятствия.

## Играть

GitHub Pages: https://masksimus.github.io/last-frontier-play/outbreak/

Эта ссылка становится доступна после успешного workflow **Publish verified Outbreak alongside existing games**. Исторические версии в корне, `/v9/`, `/v9-2/`, `/v9-3/`, `/v10/` и `/v11/` сохраняются по своим SHA-256.

## Управление

- WASD / стрелки — движение относительно экрана.
- Мышь — прицел; удерживайте левую кнопку для стрельбы.
- R — перезарядка; 1–4 / Q — оружие; пробел / G — граната.
- E — включить ближайший терминал или покинуть зачищенный сектор.
- Esc — пауза. На сенсорном экране — левый джойстик движения и правый джойстик огня, отдельные кнопки действий.

Уничтожьте гнёзда, включите терминалы и зачистите заражённых, чтобы открыть шлюз. Подкрепления конечны; раннее уничтожение гнёзд сокращает их число. Между уровнями покупайте оружие, патроны, броню и аптечки. Пистолет имеет неограниченный резерв, но требует перезарядки. Контрольные точки сохраняют начало следующего сектора и покупки.

## Сборка

```sh
cd app
npm run verify
# Полностью автономная Canvas-сборка: app/dist, app/last-frontier-release.zip.
# Распакованный index.html можно открыть напрямую.

npm ci --ignore-scripts --no-audit --no-fund
npm run build:vite
npm run verify:dist
npm run preview
# http://localhost:4173 — сборка с PixiJS и Howler.
```

Нужны Node.js 22+ и Python 3.10+. Загрузка ресурсов из внешних сетей во время игры не требуется.

## Открытые библиотеки и материалы

PixiJS 8.22.0 (MIT) рисует GPU-эффекты боя; Howler 2.2.4 (MIT) воспроизводит звук. Vite 7.3.7 (MIT) собирает зависимости локально. Версии зафиксированы в `app/package-lock.json`; точные уведомления лицензий попадают в `THIRD_PARTY_LICENSES` каждой библиотечной сборки.

Новые 44 спрайта произведены в Blender: промышленный реквизит, гнёзда, боец и мутанты с восемью направлениями. `app/assets/outbreak/LICENSE.txt` — CC0-1.0, `metadata.json` содержит размеры, точки привязки и SHA-256. Редактируемая сцена — `app/art-source/outbreak/outbreak.blend`, воспроизводимый генератор — `app/scripts/create_outbreak_blender.py`.

## Проверки

`npm run verify` проверяет правила, коллизии, достижимость целей трёх карт, обратимость проекции, упаковку и сохранение прежних публикаций. GitHub Actions дополнительно проверяет Canvas и PixiJS в Chromium для компьютера и двух ориентаций телефона. Проверка кампании использует контролируемые тестовые состояния и реальные действия огня, терминалов, выхода и магазина; это не заменяет ручное полное прохождение.

Отчёт: `app/docs/OUTBREAK_BROWSER_RESULTS.json`; скриншоты: `app/docs/screenshots/outbreak-*.png`. Тестовые методы `OutbreakDebug` доступны только с `?test=1`. Статус версии 13.0.0-rc.1 — играбельный релиз-кандидат; баланс и длительное тестирование на физических устройствах ещё требуют проверки.

# Последний рубеж — Протокол заражения

Изометрический шутер с детализированными бойцами и кибермутантами, фабричными фасадами, огнём и интерфейсом по предоставленному визуальному референсу. Три связанных уровня: открытый промышленный двор A-7, лаборатория и реактор с маткой. Стены и оборудование блокируют движение, пули и видимость; мутанты обходят препятствия и выдерживают дистанцию друг от друга.

Двор имеет широкие маршруты между шестью настоящими препятствиями, мокрый бетон с отражениями, низкие бетонные ограждения, прожекторы, дым и огонь по внешнему периметру. Физические границы оборудования видны по приподнятым площадкам. Камера оставляет больше места перед бойцом; вспышки пулемёта босса и его трассеры используют отдельную высоту.

## Управление

- WASD / стрелки — движение относительно экрана.
- Мышь — прицел; удерживайте левую кнопку для стрельбы.
- R — перезарядка; 1–4 / Q — оружие; пробел / G — граната.
- E — включить ближайший терминал или покинуть зачищенный сектор.
- Shift — рывок; F — электроимпульс (5 кристаллов). Четыре улучшения в HUD покупаются за кредиты и действуют в бою.
- Esc — пауза. На сенсорном экране — левый джойстик движения и правый джойстик огня, отдельные кнопки действий.

Пройдите десять настоящих волн в трёх секторах, уничтожьте трёх боссов и гнёзда, включите терминалы и зачистите заражённых, чтобы открыть шлюз. Подкрепления конечны; раннее уничтожение гнёзд сокращает их число. Между уровнями покупайте оружие, патроны, броню и аптечки. Пистолет имеет неограниченный резерв, но требует перезарядки. Контрольные точки сохраняют начало следующего сектора и покупки.

## Сборка

```sh
cd app
npm run verify
# Полностью автономная Canvas-сборка: app/dist, app/last-frontier-release.zip.
# Распакованный index.html можно открыть напрямую.

npm ci --ignore-scripts --no-audit --no-fund
npm run build:vite
npm run verify:dist
npm run preview
# http://localhost:4173 — сборка с PixiJS и Howler.
```

Нужны Node.js 22+ и Python 3.10+. Загрузка ресурсов из внешних сетей во время игры не требуется.

## Открытые библиотеки и материалы

PixiJS 8.22.0 (MIT) рисует GPU-эффекты боя; Howler 2.2.4 (MIT) воспроизводит звук. Vite 7.3.7 (MIT) собирает зависимости локально. Версии зафиксированы в `app/package-lock.json`; точные уведомления лицензий попадают в `THIRD_PARTY_LICENSES` каждой библиотечной сборки.

HD-набор `app/assets/siege/` содержит три прозрачных атласа: персонажи, промышленный реквизит и оружие (16 отдельных областей), а также отдельную текстуру мокрого бетона `yard-ground.webp`. Изображения созданы для проекта генератором по пользовательскому референсу; sourceRects и точки привязки — в metadata.json, точные промпты, SHA-256 и отчёты — в `app/art-source/siege/`. Текстура бетона экспортирована в WebP без изменения размера. Этому набору не приписывается лицензия Blender-материалов.

Исходные 44 спрайта произведены в Blender: промышленный реквизит, гнёзда, боец и мутанты с восемью направлениями. `app/assets/outbreak/LICENSE.txt` — CC0-1.0, `metadata.json` содержит размеры, точки привязки и SHA-256. Редактируемая сцена — `app/art-source/outbreak/outbreak.blend`, воспроизводимый генератор — `app/scripts/create_outbreak_blender.py`.

## Проверки

`npm run verify` проверяет правила, коллизии, достижимость целей трёх карт, обратимость проекции, упаковку и сохранение прежних публикаций. GitHub Actions дополнительно проверяет Canvas и PixiJS в Chromium для компьютера и двух ориентаций телефона. Проверка кампании использует контролируемые тестовые состояния и реальные действия огня, терминалов, выхода и магазина; это не заменяет ручное полное прохождение.

Отчёт: `app/docs/OUTBREAK_BROWSER_RESULTS.json`; скриншоты: `app/docs/screenshots/outbreak-*.png` и `siege-*-reference-battle.png`. Тестовые методы `OutbreakDebug` доступны только с `?test=1`. Статус версии 14.1.0-rc.1 — играбельный релиз-кандидат; баланс и длительное тестирование на физических устройствах ещё требуют проверки.

# Последний рубеж

**«Операция „Заря“» — кандидат в релиз браузерной survival-игры:** три сектора, десять волн, четыре вида оружия, боссы, восстановление ретрансляторов, контрольные точки и эвакуация. Доступны три уровня сложности. Подробности — в [описании кампании](app/docs/CAMPAIGN_RC_RU.md). Опубликованная 3D-версия V11 сохраняется отдельно.

Нужны Node.js 22+ и Python 3.11+. Canvas-сборка работает с локальными ресурсами и собирается без установки npm-пакетов и доступа к сети:

```sh
cd app
npm run verify
npm run preview
```

Для сборки с PixiJS и Howler выполните из `app/`:

```sh
npm ci --ignore-scripts --no-audit --no-fund
npm run build:vite
npm run verify:dist
npm run preview
```

Открыть `http://localhost:4173` или предпросмотр порта 4173 в удалённой среде. [package-lock.json](app/package-lock.json) фиксирует проверенные зависимости, включая PixiJS 8.22.0, Howler 2.2.4 и Vite 7.3.7.

Оба пути создают `app/dist/` и `app/last-frontier-release.zip` с `index.html` в корне. `build-manifest.json` содержит размеры и SHA-256 файлов; `npm run verify:dist` проверяет содержимое каталога и ZIP. Одинаковые исходники и версия Python дают одинаковый архив независимо от времени файлов. Лицензии библиотек включаются в `THIRD_PARTY_LICENSES/`; Canvas-сборка содержит пустой список npm-библиотек. [Исходники Blender](app/art-source/README.md), GLB и CC0-изображение ретранслятора сохранены в репозитории; рабочие `.blend` и `art-source/` исключаются из веб-архива.

В [CI](.github/workflows/release-check.yml) два независимых задания: Canvas и Vite/PixiJS. Каждое запускает Chromium в трёх размерах экрана, включая touch-профили; проверка Vite требует готового Pixi-рендерера. [Обе сборки и шесть браузерных профилей прошли](https://github.com/masksimus/last-frontier-play/actions/runs/39101610173), а локальная проверка включает 56 Node-тестов и 12 тестов упаковки на Python. CI сохраняет ZIP, манифест, браузерные отчёты и скриншоты как артефакты.

Это **release candidate**: перед публикацией ещё нужны приёмка на реальных устройствах, проверка баланса и интеграция SDK выбранного магазина. Статус AAA-ready не заявлен.

# Последний рубеж

Браузерная survival-игра: волны противников, боссы, смена оружия и улучшения. Эта рабочая версия развивает кампанию на базе Canvas-игры V8. Это **campaign release candidate**, который требует приёмки перед публикацией; он не заменяет опубликованную 3D-версию V11 и не является подтверждённым AAA-релизом.

Для локального запуска нужны Node.js 22+ и Python 3.11+. Установка npm-пакетов и доступ к сети для стандартной сборки не нужны:

```sh
cd app
npm run verify
npm run preview
```

Открыть `http://localhost:4173`. На удалённой машине порт 4173 следует открыть через предпросмотр среды. `preview` слушает все интерфейсы; для доступа только с этой машины используйте `python3 -m http.server 4173 --bind 127.0.0.1 --directory dist`.

Команда `verify` проверяет игровую логику, упаковку, собирает `app/dist/` и проверяет SHA-256 всех файлов. Готовый переносимый архив — `app/last-frontier-release.zip`; внутри `index.html` лежит в корне. Повторная сборка одинаковых исходников в одной версии Python создаёт тот же ZIP независимо от времени файлов. Изменённые, лишние или отсутствующие файлы обнаруживаются командой `npm run verify:dist`.

Стандартная сборка использует Canvas и локальные игровые ресурсы. Рабочие файлы Blender из `art-source/`, `.blend` и `.blend1` исключаются из веб-архива. PixiJS/Howler остаются дополнительным путём `npm run build:vite`, для которого нужны установленные зависимости. Этот путь не проверен в среде без сети; в текущем checkout нет npm lock-файла. Стандартная сборка не заявляет, что включает эти библиотеки; её `THIRD_PARTY_LICENSES/PACKAGES.json` содержит пустой список. Vite-путь требует оригинальные лицензии установленных пакетов.

Workflow [release-check.yml](.github/workflows/release-check.yml) проверяет текущий код и сохраняет архив как артефакт без публикации сайта. Другие workflows описывают исторические публикации V7–V11, включая сборки из закреплённых коммитов; их наличие не означает, что текущий код прошёл их приёмку. Публикация в магазине, SDK магазина, реальные устройства и полное прохождение кампании требуют отдельной проверки.

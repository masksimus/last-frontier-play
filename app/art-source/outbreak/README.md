# Outbreak isometric kit

Original CC0 artwork, authored procedurally in Blender. No third-party meshes or textures. `outbreak.blend` uses Blender's native lossless compression and remains fully editable.

Rebuild with `blender -b --python app/scripts/create_outbreak_blender.py`. The source file contains one editable collection per sprite. Orthographic camera uses a 30° elevation for a true 2:1 diamond projection. `metadata.json` records the exact projected world-origin anchor, display size and sprite SHA256.

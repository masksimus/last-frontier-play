# Последний рубеж V9 — изменение существующей V8

База: a7e4417f3d0a912b3a76c4ae9646c09273d05987, каталог app/.
Отдельная ветка: feat/v9-3d-industrial. Публикация Pages не выполнялась.

## Что реализовано

- Three.js WebGL-сцена вместо плоского спрайтового отображения; наклонная
  ортографическая камера следует за игроком. Контроль остаётся экранным.
- Отдельные лицензированные GLB Kenney/Quaternius: герой, 4 класса противников,
  оружие в модели героя, генераторы, трубы, опоры, турели и окружение.
- Реальные скелетные клипы, переходы движения/стрельбы/попадания/смерти.
- PBR-материалы, окружающие отражения, направленное освещение и динамические тени,
  независимые эффекты взрывов, дыма, искр, свет выстрела, кольцо игрока.
- Rapier: swept collision движения и рывка с укрытиями, raycast снарядов;
  общие flow fields ведут врагов вокруг препятствий.
- Боевые правила V8 сохранены: 10 волн, боссы 3/6/9, ярость, 3 вида оружия,
  прокачка, автоогонь, рекорд, рывок, мобильный джойстик, победа и поражение.
- Howler для существующих локальных звуков, выключение звука и пауза;
  ключи localStorage сохранены. Новая музыкальная композиция не создавалась.
- При отказе WebGL, модели или потере контекста игра продолжает работать
  через существующий Canvas-рендерер. Состояние боя не обнуляется.
- Пакеты фиксированы lockfile. Никаких внешних CDN в игровом рантайме.
  SDK Яндекса остаётся условным подключением /sdk.js.

## Ограничения результата

Это рабочая проверочная V9 с настоящей 3D-графикой, но не графика AAA и не
фотореалистическое совпадение с референсом. Модели бесплатных пакетов имеют
стилизованные силуэты и детализацию. Пользовательский арт-дирекшн не следует
считать полностью достигнутым. Для точного соответствия нужны специально
созданные персонажи, броня, органические боссы и окружение.

Эмуляция Android-разрешений в Chromium не заменяет испытание на Xiaomi 11T
или другом физическом устройстве. Производительность настоящего Android,
тепловой режим, браузеры производителей и модерация Яндекс Игр не проверены.

## Сборка и проверка

```sh
cd app
npm ci --ignore-scripts
npm run verify
npx playwright install --with-deps chromium
npm run test:browser
python3 -m http.server 8080 --directory dist
```

Результат: last-frontier-v9-yandex.zip. index.html лежит в корне архива.
Запуск через HTTP(S); открытие через file:// не поддерживается ES-модулями.
CI v9-staging.yml только проверяет и выгружает ZIP/протоколы, не публикует игру.
Старый production workflow намеренно не изменён: его миграция на новые имена
сборки и тесты должна быть частью отдельного решения о релизе, до merge в main.

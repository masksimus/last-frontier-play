# Проверка V9.1.0 RC1 — 17 октября 2026

База: V9 commit 2e6f7d2, ветка feat/v9-3d-industrial, PR #3.

## Функциональные проверки

40/40 тестов Node.js: боевая логика V8, столкновения Rapier, навигация,
целостность CC0 GLB, физика рывка и новые тесты AnimationMixer.
Новые тесты проверяют полную реакцию на попадание, приоритет/завершение смерти,
сброс состояния при повторном использовании актёра, паузу, обратное движение,
завершение атаки босса и поворот через ±π.

6/6 браузерных сценариев Chromium 141 / SwiftShader:

| Сценарий | Результат |
|---|---|
| Desktop 1366×768 | PASS |
| Android landscape, эмуляция 920×420 | PASS |
| Android portrait, эмуляция 393×851 | PASS |
| Принудительный Canvas | PASS |
| Отсутствующая модель GLB | PASS: резервный рендер |
| Потеря WebGL-контекста | PASS: бой продолжен в Canvas |

Проверены реальный CDP touch-ввод, смена трёх видов оружия, рывок,
пауза/возобновление, выбор улучшения, следующая волна, ярость и снаряды босса,
смена ориентации, победа, поражение и повтор игры. Нет необработанных JS-ошибок.
В штатных WebGL-сценариях нет ошибок консоли или компиляции шейдеров;
прерывание загрузки GLB намеренно даёт сетевую ошибку в негативном сценарии.
Проверены контактные тени и предел динамических теней 5 touch / 8 desktop.

## Визуальная проверка

Просмотрены кадры штатного боя и массовой сцены. Проверены раздельная геометрия,
бетон с швами/трещинами/картами рельефа и шероховатости, износ металла,
светильники, читаемость героя и экрана улучшений. Визуальный результат остаётся
стилизованным. Не заявляется совпадение с исходным AAA-референсом.
Использовать game-dev capture harness невозможно: CLI и адаптер отсутствуют.
Эти результаты получены собственными тестами проекта, а не sealed game-dev capture.

## Нагрузка и ограничения

Исправлен нагрузочный тест: получение опыта теперь не может поставить симуляцию
на паузу посередине замера. Повторный desktop-прогон подтвердил mode=running
после всех 100 кадров с 45 дополнительными противниками.

В этом прогоне: 49 живых врагов, 51 отрисовываемый актёр включая тела,
85 draw calls, 203434 треугольника, 51 контактная тень. Экономичный режим
сработал автоматически и отключил карту динамических теней. Медиана времени
кадра 550 мс, p95 900 мс в программном SwiftShader. Это плохая плавность в
данной программной среде, а не доказательство производительности телефона.
Старый замер с возможной паузой нельзя использовать для честного сравнения FPS.

Известные предупреждения: PMREM ограничивает размытие окружения; Rapier 0.19.2
выдаёт предупреждение внутренней WASM-инициализации. Vite сообщает о большом
WASM-чанке и сохранённых classic-script модулях V8. Это не ошибки выполнения.

## Поставка

ZIP с index.html в корне, локальными ассетами, лицензиями, release notes и
версионным SHA-256-манифестом: last-frontier-v9.1-rc1-yandex.zip.
Упаковщик проверяет структуру ZIP, наличие лицензий и хеш каждого файла.
Новых сторонних ассетов нет; исходные GLB остаются CC0-1.0.

GitHub CI повторяет npm run verify и все шесть сценариев на итоговом коммите.
Публикуется только /v9/ после успешного CI. Существующие 58 файлов V8
проверяются по исходному манифесту и сохраняются байт-в-байт.

Статус: релизный кандидат RC1. Окончательный production-релиз требует проверки
десяти волн на физическом Android с измерением FPS/нагрева и проверки в
кабинете Яндекс Игр. Это не выполнено удалённой эмуляцией.
